# 📘 Документація: Скрипт перевірки та патчингу `.parquet`-файлів з свічками Binance

## 🧠 Призначення

Цей скрипт автоматично перевіряє `.parquet`-файли з свічками:

* на наявність **пропущених хвилин** у таймстемпах
* на наявність **порожніх значень (`NaN`)** у свічках
* за потреби — **дозавантажує відсутні дані** з:

  * 🗃 Binance Data Vision (BDV)
  * 🌐 Binance API (якщо дозволено в конфігурації) **(краще не вмикати АПІ, ефективність майже 0, лише дуже гальмує процес)**

---

## 📂 Структура проєкту

```
📁 parquet_cheker/
├── core/
│   ├── patcher.py               # Основний патчер-скрипт
│   ├── config.py                # Конфігурація: список пар, інтервал, шляхи
│   ├── patched_parquets/        # 🟢 Паркет-файли після виправлення
│   ├── patched_reports/         # 📊 Репорти про успішне патчення
│   └── failed_patch_reports/    # ❌ Репорти про невдалі пари (де дані не знайдено)
│── requirements.txt
│──README.md
```

## ⚙️ Конфігурація `config.py`

### Основні параметри:

```python
PARQUET_FOLDER = "/шлях/до/parquet/candles"  - шлях до папки з паркетниками
PARQUET_FILE_FILTER = "BTC"  # Фільтр: BTC / USDT   - обрати які паркетники патчити, пари до BTC або до USDT

INTERVAL = "1m"               # Інтервал свічок
NUM_WORKERS = 8               # Кількість паралельних процесів
SYMBOLS_TO_CHECK = [...]      # Список пар, які треба перевірити, якщо не обрано автовизначення пар з файлу
USE_BINANCE_API_BACKUP = True  # Чи пробувати API, якщо BDV не дає файл **(ефективінсть дуже низька, а часу займе багато, краще False ставити)**

API_KEY = "..."               # Ключі Binance API
API_SECRET = "..."
```

### Автовизначення символів:

```python
AUTO_SYMBOLS_FROM_PARQUET = True
```

Якщо `True`, скрипт сам витягує всі пари з колонок у parquet-файлі і SYMBOLS_TO_CHECK можно не заповнювати

## 🚀 Як запустити

### 1. Встановити залежності:

```bash
pip install -r requirements.txt
```

### 2. Вказати у `config.py`:

```python
PARQUET_FILE_FILTER = "BTC" або 'USDT'
AUTO_SYMBOLS_FROM_PARQUET = True або False
SYMBOLS_TO_CHECK = пропустити якщо AUTO_SYMBOLS_FROM_PARQUET = True, або вказати список пар вручну, які треба патчити
```

### 3. Запустити скрипт:

```bash
python core/patcher.py
```

## 📝 Що робить скрипт?

🔄 Для кожного `.parquet` файлу:

* визначає всі символи (наприклад, `ADA_BTC`, `ETH_BTC`, `DOGE_BTC`)
* створює повний список очікуваних таймстемпів на місяць
* знаходить пропущені таймстемпи (тобто хвилини, яких немає)
* знаходить порожні рядки (з `NaN`)
* пробує знайти відсутні свічки:

  * ⚙️ спочатку через Binance Data Vision (zip-архів)
  * 🌐 потім через Binance API (якщо дозволено)
* якщо дані знайдені — **вставляє їх** в DataFrame
* зберігає **оновлений `.parquet` файл** в `patched_parquets/`

## ✅ Часті кейси

| Сценарій                      | Як зробити                         |
| ----------------------------- | ---------------------------------- |
| Працювати тільки з BTC парами | `PARQUET_FILE_FILTER = "BTC"`      |
| Автоматично знайти всі пари   | `AUTO_SYMBOLS_FROM_PARQUET = True` |
| Не використовувати API        | `USE_BINANCE_API_BACKUP = False`   |

---

## ❓ Часті питання

### 📌 Якщо немає даних ні в BDV, ні в API?

→ Пари записуються у файл `failed_patch_reports/...csv`

### 📌 Якщо всі дані вже є в parquet?

→ Скрипт нічого не змінює, просто лог: `✅ Saved: ...`
