# 📊 Документація: Скрипт перевірки та патчингу `.parquet`-файлів зі свічками Binance

## 🧠 Призначення

Цей скрипт автоматично перевіряє `.parquet`-файли з хвилинними свічками:

- 🔍 на наявність **пропущених хвилин** у таймстемпах
- 🕳️ на наявність **порожніх значень** (`NaN`) у свічках
- 💾 за потреби — **дозавантажує відсутні дані** з:
  - 🗃 **Binance Data Vision (BDV)**
  - 🌐 **Binance API** (якщо дозволено в конфігурації)
